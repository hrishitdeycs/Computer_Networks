In **Cisco Packet Tracer**, you implement a **router-based connection between devices** when you need communication across different networks.

### **What**

A router connects **multiple networks (LANs/WANs)** and routes data between them using IP addresses.

### **Why**

You use a router because:

* Devices in different networks (different IP subnets) **cannot communicate directly**
* It enables **inter-network communication**
* It provides **routing, path selection, and sometimes security (ACLs)**

### **When**

You implement a router when:

* You have **more than one subnet** (e.g., 192.168.1.0/24 and 192.168.2.0/24)
* You need **PCs in different LANs to communicate**
* You are simulating **real-world networks (office branches, ISP routing, etc.)**

**In short:** use a router in Packet Tracer whenever communication must happen **between different networks, not just within one LAN**.
